From the `reminders/read directory`:


### Compile and run unit tests

```sh
osacompile -o read.scpt read.applescript &&
osascript read.test.applescript "$PWD/read.scpt"
```

Expected output:

```text
PASS: 4 tests
```


### Read actual reminders


```sh
osascript read.applescript
```

This executes the `run` handler, which calls `remindersToJSON()` and prints JSON containing your actual reminders. macOS may prompt for permission to access Reminders.
