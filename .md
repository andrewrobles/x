# AppleScript

Get all reminder names
```
tell application "Reminders"
    get name of every reminder
end tell
```

Get reminder details

```
tell application "Reminders"
	set r to first reminder whose name is "AppleScript Test"
	
	set reminderName to name of r
	set reminderCompleted to completed of r
	set reminderCreationDate to creation date of r
	set reminderCompletionDate to completion date of r
	
	return {reminderName, reminderCompleted, reminderCreationDate, reminderCompletionDate}
end tell
```

List reminders by list


```
tell application "Reminders"
	set output to ""
	
	repeat with reminderList in lists
		set output to output & "LIST: " & name of reminderList & linefeed
		
		repeat with r in reminders of reminderList
			set output to output & "  " & name of r & linefeed
		end repeat
		
		set output to output & linefeed
	end repeat
	
	return output
end tell
```

Delete a reminder
```
tell application "Reminders"
    set r to first reminder whose name is "DELETE ME"
    delete r
end tell
```
